# MeechyLand

Private family browser Minecraft for Mila.

## Files
- START_HERE_FOR_MILA.txt
- GROWN_UP_SERVER_SETUP.txt
- GIVE_MILA_HER_STUFF.txt
- index.html (custom loader)

## Quick Start
1. Set up private 1.8 server with whitelist + Creative for Mila
2. Put your server WebSocket address in index.html
3. Mila opens the page, types Mila, joins
4. Run the give commands so she has her special items

GitHub Pages: Enable in repo Settings → Pages → main branch / root.
